# 🎬 Netflix Content Analysis

An exploratory data analysis (EDA) of Netflix's content catalog, built with **Python**, **pandas**, and **matplotlib**. The project uncovers patterns in content type, ratings, production countries, movie duration, and release trends over time.

## 📊 Key Visualizations
- **Movies vs TV Shows** — distribution of content type across the platform
- **Rating Distribution** — breakdown of content by maturity rating (G, PG, PG-13, TV-MA, etc.)
- **Duration Spread** — histogram of movie runtimes
- **Top Producing Countries** — countries contributing the most titles
- **Release Year Trend** — number of titles released per year

## 🛠️ Tools & Libraries
- Python
- pandas — data cleaning & aggregation
- matplotlib — data visualization

## 🔍 Key Insights
- Movies significantly outnumber TV Shows in the catalog (roughly 2:1).
- Canada, Mexico, and France are among the top contributing countries by title count.
- Content additions show notable fluctuation across release years, with recent years seeing renewed growth.
